# Changelog

## Unreleased

- [SECURITY] No model- or transcript-derived field reaches a tracker with a live mention or cross-reference any more. A tracker's title and summary, a Jira description and a GitHub issue body are all shown to other people — GitHub autolinks **and notifies** `@mentions` there and resolves `#123` cross-references, and a tracker can show the same text again in notifications and activity feeds — so anyone who only controls what is on the recorded screen could have had the user's export ping arbitrary accounts in their repository, or forge a cross-reference to an unrelated issue. Every untrusted field that can carry a live trigger is now neutralized on the way out (a zero-width space after `@`, `#` and `GH-`, which leaves the text visually identical — including when a combining mark or a zero-width joiner hides the trigger inside a character cluster), the Windows session title included, and the deduplication hint in the GitHub body can no longer break out of the code span it is rendered in. The neutralization runs before the length cap, and the cap counts UTF-16 code units the way the trackers count them, so the field the tracker receives fits GitHub's 256 and Jira's 255 characters even when the title is dense in astral-plane characters; both ports now collapse and cut a title the same way, so they send the same title.
